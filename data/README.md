# Dữ liệu demo

`demo/demo-a/` chứa JSON/GeoJSON mô phỏng được xuất từ [bộ sinh TypeScript](../src/demo/demo-a/). Đây không phải dữ liệu khảo sát hoặc nguồn dẫn đường thực tế.

Sau khi chỉnh bộ sinh/đáp án, chạy `npm run emit:fixtures` rồi kiểm tra diff và `npm test`. Chiều dài dùng `length_m` trong bảng cạnh, không suy ra từ tọa độ minh họa. Xem [kịch bản mock](../docs/demo/mock-data.md).
